# Milestone report: M3 Exports and sharing

2026-10-11

## Acceptance criteria

| Criterion | Result |
| --- | --- |
| The printed check bar measures 100 mm | **In the file:** every page carries the bar. In PDF units it is exactly 100 mm (283.465 pt); a unit test checks this on every page. **On screen:** PDFium, an independent renderer, rasterised the template at 300 dpi and measured the bar at 100.08 mm, which is 100 mm plus the width of the end ticks. **On paper:** not yet checked. A real printout needs a ruler (see below). |
| Golden tests confirm cutout sizes and centres to 0.05 mm | `tests/exports.test.ts` exports a fixture (`fixtures/projects/export-golden.json`) to SVG, DXF and PDF. Independent readers in `tests/export-parse.ts` then measure every cutout and hole against values worked out by hand. The fixture has a 45° turned instrument, a 30° turned rounded rectangle, a D-shaped custom cutout with an arc, panel fixings and a curved outline. All are within 0.05 mm in all three formats, and on every tile of the template. |
| Fixture projects round-trip through link and file unchanged | Every file in `fixtures/projects/` survives `link → decode` and `file → parse` deep-equal to the original (`tests/share.test.ts`, `tests/exports.test.ts`). In the browser, a share link opened in a fresh browser context gives an identical document (`e2e/m3-exports.spec.ts`). |
| An oversize link falls back to a file | Over the length target (default 8,000 characters), the Share dialog offers **Save project file** instead of a link. A Playwright test covers this with a 1,500-point traced template, which makes a 16,134-character link, and checks the downloaded file. |

**Test totals:** typecheck clean, 119 Vitest tests (34 new), 15 Playwright flows (7 new).

**Performance:** frame times at 200 parts are unchanged (median frame 16.7 ms, front and rear). The exporters are code-split: they add 9.8 kB gzip, loaded on first export. The main bundle is 137 kB gzip.

**Independent checks** (run outside the repo; not project dependencies):

- ezdxf's auditor reads both DXFs as R12 in millimetres, with 0 errors and 0 fixes.
- pypdf parses every PDF in strict mode.

## What was delivered

All exports are under **File › Export… (Ctrl+E)**, and each also has a palette command.

| Output | Notes |
| --- | --- |
| Cut file, SVG | 1:1, `width`/`height` in mm. Inkscape layers: `OUTLINE`, `CUTOUTS`, `SCREW_HOLES`, `BEND_LINES`, `ENGRAVING`, plus `KEEP_OUTS_REFERENCE`, `DIMENSIONS_REFERENCE` and `NOTES_REFERENCE`, which are not cut. Circles stay circles and arcs stay arcs. |
| Cut file, DXF | R12 ASCII with the same layers. Arcs are stored as bulges, holes as `CIRCLE`s, text is ASCII. |
| Printable template, PDF | Tiled on A4, portrait or landscape, whichever needs fewer pages. Tiles overlap by 12 mm and have alignment marks. Every page has a check bar, the stamp, page numbers and a tile map. A cover sheet holds the overview, assembly steps, layer key and title block; notes that don't fit continue on extra pages. The file asks viewers to print at actual size. |
| Front render, PNG | 2,400 px on the long side. |
| Front render, PDF | One A4 landscape page with a title block and approximate scale. |
| Bill of materials, CSV | One row per distinct part. Variants with different parameters, such as a 3 A and a 5 A fuse, get separate rows. Includes labels, parameters, datasheet link, weight and current per unit and in total, and the verified/unverified status. Unknown values stay blank and are counted in the totals row, never estimated. The price column is blank (see below). Cells a spreadsheet would treat as formulas are made safe. |
| Project file, JSON | As before, and now also through Export. A file dropped on the window opens. A file from a newer version gets a clear message. |
| Share link | **File › Share link…** copies a link with the whole design after the `#`. Opening it makes your own copy. The work it replaces is kept and can be restored from **File › Restore work from before a share link**. The link is then cleared from the address bar. |

**Every drawing** carries:

- a title block: project, registration, glider type, revision, date, author, template and material;
- the stamp **PLANNING AID - VERIFY BEFORE CUTTING**;
- a note that the design is not an approval;
- the list of open warnings.

**Error gate:** with errors open, the cut files and the template are blocked. You can tick an override; it is stamped on the SVG and DXF notes layer, in red on every template page, and with the full error list on the cover. Renders, the bill of materials and the project file are never blocked. The override resets every time the dialog opens.

**Promised in M1 and delivered here:**

- **Text tool (T):** engraved or printed text. Letter height is the cap height in mm. Engraved text goes in the cut file's `ENGRAVING` layer; printed text appears only in renders.
- **Dimension tool (D):** click two points. A point on a part's centre attaches the dimension to that part, so it follows the part. Shift gives horizontal or vertical.
  - Dragging a dimension slides its line.
  - Deleting a part deletes the dimensions on it, and undo restores both.
  - Dimensions export on a reference layer.
- A **Revision** field in the project properties, used in the title block.

**Decisions** are in [ADR 0008](../adr/0008-exports.md) (exports) and [ADR 0009](../adr/0009-share-links.md) (share links).

## Choices made without asking (rule 11)

These are not safety thresholds; tell me if you want any changed.

- **Exports have no PDF or DXF library** (ADR 0008). The writers are small and cross-checked as above. pdf-lib (MIT) is the fallback if we need embedded fonts.
- **Cut-file contents:**
  - The template's panel fixings go on the `SCREW_HOLES` layer, because a new panel needs them drilled.
  - Keep-outs and dimensions are exported, as reference only.
- **Template layout:**
  - Template tiles overlap by 12 mm, with 10 mm page margins.
  - Paper is A4 only; Letter is parked.
- **Share-link length limit:** stays at 8,000 characters. It can be changed in the Share dialog and is remembered per browser.
- **The bill of materials has no prices.** Retailer prices must stay out of the repo (rule 7), and the shared catalogue has none.
- **Missing current draw counts as unknown in the totals.** Several generic parts may be powered, so leaving them out would understate the total.

## Please check

1. **Print the template.** Print `Export › Printable template` for the sample project at 100% (Actual size), and measure the check bar with a ruler. Then hold a printed 57 mm or 80 mm cutout against a real instrument. This is the one acceptance check only paper can do.
2. **Try the cut files in your CAM software.** If you have a panel shop or laser cutter in mind, try both files there. R12 DXF is the most widely read format, but some shops have house rules: layer names, colours, and text converted to outlines.
